## 1. 项目概述

接管一套 **Android 自动化赚钱项目**（`android_autopilot`），核心逻辑：

- 真机（vivo V1911A）通过 **uiautomator2 + ADB** 控制；
- 对一批「看视频 / 阅读 / 短剧 / 签到 / 提现」类 App 执行签到、看视频、领金币、提现等任务；
- **VLM 视觉兜底**：UI dump 拿不到坐标时，用截图 + VLM 定位 `x,y` 再点击；
- **真人模拟**：随机时间、轨迹滑动、点击抖动，降低风控；
- 收益写入 **SQLite 记账**。

## 5. 踩坑与经验（避免重复劳动）

### 5.1 连接层
1. **USB 直连必断流**：vivo 经 USB/无线 adb 常出现 62 字节截图即断、PnP 轮询空白。**解法**：趁 USB 短暂 online 执行 `adb tcpip 5555`，再用 `lan_scan_5555.py` 扫网段定位 `192.168.1.54:5555`，`adb connect` 后走无线稳定通道。
2. **PowerShell 中 `&&` 不是有效分隔符**；adb 命令须用 Job/Start-Process 做受控超时，否则 shell 会卡满 600s。
3. **截图字节截断**：早期用 cmd 重定向产出坏 PNG；**必须**用 `adb exec-out screencap -p` 由 python 直接读 stdout 写字节（见 `adb_shot.py`）。
4. 真机断网/重启后无线连接失效，需 `adb connect` 重连或重走 tcpip 流程。

### 5.2 App 操作层
5. **开屏广告期按 BACK 会直接退出 app**：赚钱/资讯类 app 的 5s splash 内按返回 = 退出应用（UI 回到桌面）。解法：**不要用 BACK 跳广告**，延长等待 12-20s 让广告自然结束，再 dump 或截图。
6. **枚举图标包名不用 aapt**：对桌面/文件夹图标逐个 `input tap`，随后用 `dumpsys window` 的 `mCurrentFocus` / `mFocusedApp`，或 `dumpsys activity activities` 的 `topResumedActivity` / `mResumedActivity` 读取前台包名（多级兜底，见历史脚本）。文件夹先 tap 文件夹(等2s)再 UI dump 取 item bounds，逐个 tap(等7-10s)。
7. **launcher 文件夹误判**：`没写`/`运行未通过`/`运行通过` 实为文件夹（content-desc 前缀「文件夹-」），点击后 UI 不变属正常；展开后才是 App。用 UI dump + VLM 截图交叉验证。
8. **启动 App 正确姿势**：`cmd package resolve-activity --brief <pkg>` 取组件后 `am start -n <pkg>/<activity>`；直接 `am start -n <pkg>` 无效（Bad component）。

### 5.3 VLM 层
9. VLM 未命中返回 `{x:null,y:null}` 是正常，先裸调网关区分「未命中」与「后端故障」，避免误报。
10. 合成图验证 VLM 误差约 40px，但纯色图不能证明端到端，必须用**真实截图**回测（`e2e_vlm_real.py`）。
11. 旧 `e2e_vlm.py` 硬编码原机路径 `D:\Users\Mass` 且用 `VisionEngine.__new__`，会 AttributeError；本机用 `e2e_vlm_adapt.py`（VisionLocator + 局域网网关）。
