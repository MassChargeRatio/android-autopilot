## 2. 根因（三条，都附原文代码）

### R1 `corner_fallback` 的触发判据太宽 → 在视频流首页上 100% 误触发

`behavior_runner.py` 里：

```python
POPUP_AD_MARKERS = ("广告", "跳过", "跳转", "打开", "下载", "安装")
```

`_popup_close_one()` 的判断是：

```python
xml = self._dump_safe()
if not any(m in xml for m in POPUP_AD_MARKERS):
    return False  # 无广告特征：干净屏，不动坐标/返回键
```

快手首页是短视频流，每一屏的 content-desc 里天然带「下载」「打开」「广告」。
于是「干净屏」判定永远不成立 → 每轮都走 corner 兜底 → 盲点右上角 → 循环到 `max_rounds`。

**这不是配置问题，是判据问题。**

### R2 关闭动作之后不验证「屏幕真的变了」

`_step_dismiss_popups()` 的循环体：

```python
for rnd in range(1, max_rounds + 1):
    xml = self._dump_safe()
    ...黑名单检查...
    if not self._popup_close_one(texts, ids, corner, back_key, app_name, rnd):
        return False
    self.human.think()
    time.sleep(1.0)
```

`_popup_close_one` 返回 True 只表示「我执行了一个动作」，**不表示这个动作有效**。
点了没反应也照样 `think() + sleep(1.0)` 进入下一轮。

### R3 每轮 dump 两次

`_step_dismiss_popups` 调一次 `_dump_safe()`（黑名单检查），
`_popup_close_one` 内部又调一次（广告特征检查）。
1080×2340 上一次 `dump_hierarchy` 实测 0.3–1.5s，纯重复开销。

## 3. 目标 A：弹窗清扫精准化

### A1 每轮只 dump 一次

- 把 `_step_dismiss_popups` 里已经拿到的 `xml` 传进 `_popup_close_one`，删掉内部那次 `_dump_safe()`。
- **验收**：新增测试，桩设备统计 `dump_hierarchy` 调用次数，`max_rounds=3` 且屏幕干净时总次数 == 1。

### A2 关闭动作必须验证屏幕变化

- 每执行一个关闭动作后，取一次「屏幕指纹」，与动作前比较；
  **没变 → 立刻 `return False`，不再进入下一轮**。
- 指纹二选一见 §5 Q3。可直接复用 `landing.py` 的 `dhash()` + `hamming()`。
- **验收**：桩设备让 dump 恒等（模拟点了没反应），`max_rounds=3` 时只跑 1 轮就退出，
  日志出现类似 `弹窗清扫: 屏幕无变化，提前结束`。

### A3 收紧 corner 兜底判据

- 现在用「文案里出现广告词」判断，必须换掉。可选判据（任选其一或组合）：
  - XML 里出现对话框/弹窗容器特征（`class="android.app.Dialog"`、全屏遮罩节点）；
  - 与上一轮相比节点数骤降 ≥40%（说明有东西被遮住了）；
  - 连续两轮指纹不变才允许试一次 corner，且**整次清扫最多试一次**。
- **硬约束**：无论怎么收紧，**不许放宽 `back_key` 的触发条件**。
  干净屏上按 BACK 会退出 App 甚至退到桌面，这是破坏性操作。

### A4 支持 per-app 弹窗关闭坐标

- 新增可选键 `popups.close_points`：`[{x, y, desc}, ...]`，归一化 0–1，按序尝试。
- 立卡现场实测：快手「瓜分百亿金币」弹窗的关闭 X 在 **(983,456)**（归一化 0.910/0.195），
  而全局兜底 (1004,257) 打不中它——这正是 R1 空转 37 秒的直接原因。
- **验收**：老配置不写这个键 → 行为与改前逐字节一致。

## 4. 目标 B：超时收窄

### B1 `any_of` 整体预算

现状：单分支 `timeout: 8`，实测一次全 miss 要 **26s**（分支串行 + 每分支内部重试）。
目标：引入整体预算概念，默认值 = 现行为（不破坏兼容），由配置显式收窄。
具体形态见 §5 Q1。

### B2 `click_first` 内部轮询粒度

现状：`self._locate(k, v, timeout=per, ...)` 一次性阻塞 `per` 秒。
目标：改为 250ms 粒度轮询，命中即返回；未命中不要睡满剩余预算才退出。
**注意**：`_locate` 在 `locator.py`，改它会影响所有调用方（含弹窗清扫的 0.8s/0.5s），
必须逐个确认语义没变。

### B3 落地校验重试前先判断「是否已在目标页」

现状：phash 失败 → 原地再点一次 → 再等 settle(3.0) → 再判 → 13s 没了。
目标：重试前先用**同一次** dump 判断当前页是否已经是目标页（节点特征/文案），
是则跳过重试，直接放行。

## 5. 三个必须你拍板的问题

### Q1 `any_of` 收窄怎么落地？

- **方案甲**：直接改默认值（8s→4s，整体 30s→12s）。省事，但**改了老配置的行为**，
  与「零行为回归」冲突。
- **方案乙**：新增 `timeouts.any_of_total`（默认 30，保持兼容），配置里设 12 才生效。
  兼容，但要动 34 份配置才拿得到收益。
- **我的倾向**：乙。理由：这个项目的纪律是「老配置零影响」，甲会一次性改掉 34 个 App 的时序。

### Q2 `corner_fallback` 要不要直接删掉？

今天唯一的实证是：它在快手首页**连打 3 轮、100% 无效、且可能点到真 UI**。
但它当初是为「右上角 X 没有文案也没有 id」的弹窗加的。
- **我的倾向**：保留能力，但默认关闭（`corner_fallback: false`），
  需要它的 App 在配置里显式开。这样既不丢能力，也不再误伤。

### Q3 「屏幕变了」用什么判？

- **dump 指纹**（节点文本+坐标拼哈希）：不用截图，但每次 ~0.3–1.5s，而 A1 刚省下一次 dump。
- **dhash 截屏**：快（一次 `screencap` ~0.2s），但引入截图链路，且动态内容（视频流）会让 dhash 天然抖动，
  需要设阈值（`landing.py` 的经验值是 hamming ≤ 8 算「同一屏」）。
- **我的倾向**：dump 指纹。理由：清扫本来就为弹窗服务，弹窗是节点结构变化，
  dump 指纹对它更敏感；且视频流的 dhash 抖动会制造假「变化」，让 A2 失效。

class BehaviorRunner:
    """行为执行层：顶层流程、动作分派、全部 step 原语、收益识别。"""

    def run_app_flow(self, app_cfg: dict, intents: list):
        """按顺序对某 app 执行一组意图。intents: [(intent_id, keyword), ...]"""
        app_name = app_cfg.get("name") or app_cfg.get("package") or "?"
        pkg = app_cfg.get("package")
        if not pkg:
            self.recorder.log("app 配置缺少 package，跳过", app_name, "WARN")
            return

        # dry-run：只打印执行计划，不触碰设备
        if self.dry_run:
            self.recorder.log(f"[dry-run] 预览计划：{app_name} ({pkg})", app_name)
            for intent, kw in intents:
                bid = self._resolve(app_cfg, intent)
                if bid is None:
                    self.recorder.log(
                        f"  意图[{intent}]({kw}) 未配置行为，跳过", app_name, "WARN")
                    continue
                bid_cfg = app_cfg["behaviors"][bid]
                if not self._window_open(bid_cfg, app_name, intent, kw, dry=True):
                    continue
                actions = self._pick_variant(self._behavior_actions(bid_cfg),
                                             app_name, bid)
                self.recorder.log(f"  意图[{intent}]({kw}) -> 行为[{bid}]:", app_name)
                for a in actions:
                    self.recorder.log("      - " + json.dumps(a, ensure_ascii=False),
                                      app_name)
            return

        # 1) 启动 app（即使已有 open 步骤也确保一次）
        #    launch_reset: true → 冷启动，避免恢复上次停留的子页面（tab 类入口必需）
        #    返回 False = 包未安装，必须整单跳过：否则盲点坐标会落到前台别的 App 上
        #    （2026-10-30 趣头条未安装，坐标点进了微信）。注意用 `is False` 判定，
        #    因为测试里 `_open_app` 被 stub 成返回 None 的 lambda。
        if self._open_app(pkg, app_name,
                          reset=bool(app_cfg.get("launch_reset"))) is False:
            self.recorder.log(f"{app_name} 启动失败（未安装），跳过本次全部行为",
                              app_name, "ERROR")
            return

        # 2) 逐意图执行
        for i, (intent, kw) in enumerate(intents):
            bid = self._resolve(app_cfg, intent)
            if bid is None:
                self.recorder.log(
                    f"意图[{intent}](触发词:{kw}) 在 {app_name} 未定义对应行为，跳过",
                    app_name, "WARN")
                continue
            bid_cfg = app_cfg["behaviors"][bid]
            if not self._window_open(bid_cfg, app_name, intent, kw):
                continue
            # 行为之间复位：上一个行为可能已把 App 留在二级/三级页，
            # 不复位则本行为会从脏页面起步（详见 _reset_to_landing 注释）。
            if i > 0:
                self._reset_to_landing(pkg, app_name)
            actions = self._pick_variant(self._behavior_actions(bid_cfg),
                                         app_name, bid)
            # F1：行为执行前全局弹窗清扫（"看到就关"；黑名单熔断仅告警不拦截行为）
            self._maybe_sweep_popups(intent, bid, app_name)
            self.recorder.log(
                f"开始执行行为[{bid}] 动作数={len(actions)}", app_name)
            ok = self._run_actions(actions, app_name, bid)
            if not ok:
                self.recorder.log(
                    f"行为[{bid}] 执行未完成（部分步骤未找到元素已跳过）",
                    app_name, "WARN")
            self.human.think()

        # 3) 自然退场（真人换台/锁屏前的随手操作）
        self._close_app(app_name)

    # ---------- 第4步：behavior 时间窗（AUTOP-SELFSEARCH-2026-10-20） ----------
    # 用户原话：「常用步骤的共性」——签到/领现金类行为常有时效窗口（凌晨福利、
    # 每日首签等）。behaviors[bid] 兼容两种形态：
    #   * list：旧格式，动作列表；
    #   * dict：新格式 {window: {start, end}, actions: [...]}（window 可选）。
    # 窗口外：记 WARN「跳过(BLOCKED)」跳过本意图，不报错、不打断整条流程。
    @staticmethod
    def _parse_hhmm(s):
        """解析 "HH:MM" / "HH:MM:SS" -> 当日分钟数；失败返回 None。"""
        if s is None:
            return None
        s = str(s).strip()
        m = re.match(r"^(\d{1,2}):(\d{2})(?::\d{2})?$", s)
        if not m:
            return None
        hh, mm = int(m.group(1)), int(m.group(2))
        if not (0 <= hh <= 23 and 0 <= mm <= 59):
            return None
        return hh * 60 + mm

    def _in_window(self, win, now=None):
        """行为时间窗判定。返回 True=窗口内/无法判定（放行）；False=窗口外。

        - window 缺失、非 dict、start/end 解析失败 -> True（不因配置问题堵死行为）；
        - start <= end -> 窗口内 = start <= now <= end；
        - start >  end -> 跨午夜窗口：now >= start 或 now <= end 均算窗口内。
        now 形如 "HH:MM"，None 取当前时间。
        """
        if not isinstance(win, dict):
            return True
        start = self._parse_hhmm(win.get("start"))
        end = self._parse_hhmm(win.get("end"))
        if start is None and end is None:
            return True
        if now is None:
            now = time.strftime("%H:%M", time.localtime())
        cur = self._parse_hhmm(now)
        if cur is None:
            return True
        if start is None:
            start = 0
        if end is None:
            end = 23 * 60 + 59
        if start <= end:
            return start <= cur <= end
        return cur >= start or cur <= end

    @staticmethod
    def _behavior_actions(bid_cfg):
        """behaviors[bid] 双形态取动作：list 原样；{window, actions} 取 actions。"""
        if isinstance(bid_cfg, dict) and "actions" in bid_cfg:
            return bid_cfg["actions"]
        return bid_cfg

    @staticmethod
    def _behavior_window(bid_cfg):
        """behaviors[bid] 双形态取 window：无 window 返回 None。"""
        if isinstance(bid_cfg, dict) and isinstance(bid_cfg.get("window"), dict):
            return bid_cfg["window"]
        return None

    def _app_extras(self, app_name):
        """解析 App 级 extra_candidates（词表微调，惰性缓存）。

        candidates_from 自搜寻时，把 config/apps/<app>.yaml 里的
        `extra_candidates` 段并入全局词表。读取失败返回 {}（不中断执行）。
        """
        cache = getattr(self, "_extras_cache", None)
        if cache is None:
            cache = self._extras_cache = {}
        if app_name in cache:
            return cache[app_name]
        extras = {}
        try:
            import config_loader
            path = config_loader.app_config_path(app_name)
            if os.path.isfile(path):
                app = config_loader._load_yaml(path) or {}
                extras = app.get("extra_candidates") or {}
        except Exception:
            extras = {}
        cache[app_name] = extras
        return extras

    def _window_open(self, bid_cfg, app_name, intent, kw, dry=False):
        """行为窗口门控：窗口外记 WARN 跳过(BLOCKED)并返回 False；否则 True。"""
        win = self._behavior_window(bid_cfg)
        if win and not self._in_window(win):
            where = "dry-run" if dry else f"触发词:{kw}"
            self.recorder.log(
                f"意图[{intent}]({where}) 行为不在时间窗内，跳过(BLOCKED)",
                app_name, "WARN")
            return False
        return True

    def _resolve(self, app_cfg, intent):
        behaviors = app_cfg.get("behaviors", {}) or {}
        imap = app_cfg.get("intent_map", {}) or {}
        bid = imap.get(intent)
        if bid and bid in behaviors:
            return bid
        return intent if intent in behaviors else None

    def _pick_variant(self, actions: list, app_name: str, bid: str) -> list:
        """行为序列多样化：behaviors[bid] 支持「多候选模板」[[..],[..]]。

        每次执行以 _diversify_prob 概率从候选模板里随机挑一条，
        并排除上一次用过的，避免连号重复同一套路径（replay 检测点）。
        单模板（旧格式）时原样返回。
        """
        if not actions or not all(isinstance(a, list) for a in actions):
            return actions
        n = len(actions)
        if n == 1:
            return actions[0]
        if random.random() > self._diversify_prob:
            return random.choice(actions)
        try:
            cand = [i for i in range(n) if i != self._variant_last.get(bid, -1)]
            idx = random.choice(cand) if cand else random.randrange(n)
        except ValueError:
            idx = random.randrange(n)
        self._variant_last[bid] = idx
        self.recorder.log(f"  行为[{bid}] 命中候选模板 #{idx+1}/{n}",
                          app_name, "DEBUG")
        return actions[idx]

    # ---------- 动作执行 ----------
    def _run_actions(self, actions: list, app_name: str, bid: str) -> bool:
        # 第3项（AUTOP-NL-2026-10-22）：把当前行为 ID 挂到实例上，
        # 供 click_first 在未写 candidates_from 时自动推断词表类别。
        self._current_bid = bid
        all_ok = True
        for act in actions:
            # v6 S1：编译层只做**校验**，不接管执行。
            # 为什么编译失败也必须继续跑：如果这里 `continue`，一个"新加了但没登记
            # 映射"的 type 会让整条链静默失效，而日志只留一句 WARN —— 那是最难查的
            # 故障形态。所以失败只记 WARN，随后照旧用原 dict 执行，由分派表决定命运
            # （未知 type 仍会被 _run_kind 记「未知动作类型」并返回 False）。
            self._validate_step(act, app_name)
            try:
                ok = self._exec_step(act, app_name)
            except StepError as e:
                # 真人式处理：找不到就挠头一下，继续下一个意图，不硬崩
                self.recorder.log(f"步骤失败: {e}", app_name, "WARN")
                all_ok = False
                self.human.think()
                continue
            if not ok:
                # dismiss_popups 返回 False = 屏幕干净、无弹窗可关，这正是清扫动作
                # 的目标状态，不应算失败（2026-10-25 蛋花实测：干净屏被判「步骤失败」，
                # 把已成功的签到行为整体标成「执行未完成」）。
                if act.get("type") == "dismiss_popups":
                    self.recorder.log("弹窗清扫: 屏幕干净，无需处理", app_name)
                    continue
                # B6：定位类动作未命中返回 False，按原消息文本记「步骤失败」
                self.recorder.log(
                    f"步骤失败: {self._last_fail or '动作未命中'}",
                    app_name, "WARN")
                all_ok = False
                self.human.think()
        return all_ok

    def _validate_step(self, act, app_name: str) -> None:
        """编译期校验（v6 S1）。**只记日志，不影响执行**。

        能抓到的都是"配置写错、跑起来必然静默失败"的形态：未知 type、
        action 与 type 冲突、click 缺定位字段、flow 既无 branches 也无 candidates_from。
        每条只在**该 step 首次**出现时记一次，避免一次运行刷满日志。
        """
        if not isinstance(act, dict):
            return
        key = id(act)
        seen = getattr(self, "_validated_ids", None)
        if seen is None:
            seen = self._validated_ids = set()
        if key in seen:
            return
        seen.add(key)
        try:
            compile_step(act)
        except ValueError as exc:
            self.recorder.log(f"步骤编译校验失败（仍按原样执行）: {exc}",
                              app_name, "WARN")

    def _exec_step(self, act: dict, app_name: str) -> bool:
        return self._dispatch_step(act, app_name)

    # B7：正常路径与探测路径分拆 —— 视觉门控从实例标志位改为显式参数链。
    # 教训：早期用 `self._probe_no_vision` 在 any_of 循环里"临时改写再还原"，
    # 一旦中途异常或新增直调点就会留下脏状态，且测试只能靠反证用例兜底。
    # 现在 allow_vision 显式贯穿：_dispatch_probe -> _step_click_* / any_of 分支。
    def _dispatch_step(self, act: dict, app_name: str) -> bool:
        """正常路径：动作前 delay+maybe_wander（原 ritual=True 语义）。"""
        self.human.delay()
        # 随机"分心"
        if self.d is not None:
            self.human.maybe_wander(self.d)
        return self._run_kind(act, app_name, allow_vision=True)

    def _dispatch_probe(self, act: dict, app_name: str, allow_vision: bool) -> bool:
        """探测路径：any_of/random 分支内动作，无 ritual，视觉门控显式参数。"""
        return self._run_kind(act, app_name, allow_vision=allow_vision)

    def _run_kind(self, act, app_name: str, allow_vision: bool = True) -> bool:
        """按 type 分派到对应 step 原语，返回 True=成功/命中，False=未命中。

        入参可以是 dict（现有全部调用路径），也可以是 v6 的 Step 对象；
        **执行永远用 `step.raw`** —— 编译层不参与执行，所以行为零变化。
        不做"从 Step 反推 legacy type"这种转换：反推是双向映射，一旦某条
        映射漏了，就会点错坐标或漏点一步，而且很难在测试里被发现。
        """
        raw = act.raw if isinstance(act, Step) else act
        t = raw.get("type")
        fn = {
            "wait": self._step_wait,
            "think": self._step_think,
            "click": self._step_click,
            "click_text": self._step_click_text,
            "click_id": self._step_click_id,
            "click_desc": self._step_click_desc,
            "click_point": self._step_click_point,
            "click_first": self._step_click_first,
            "swipe": self._step_swipe,
            "swipe_natural": self._step_swipe_natural,
            "captcha": self._step_captcha,
            "random": self._step_random,
            "any_of": self._step_any_of,
            "scroll_to": self._step_scroll_to,
            "back": self._step_back,
            "home": self._step_home,
            "dismiss_popups": self._step_dismiss_popups,
            "reward": self._step_reward,
            "ensure": self._step_ensure,
        }.get(t)
        if fn is None:
            self.recorder.log(f"未知动作类型: {t}，已忽略", app_name, "WARN")
            return False
        cat = ACTION_CATEGORY.get(t)
        if cat is None:
            # 分派表有、分类表没有：新增 type 忘了登记分类，属维护错误。
            self.recorder.log(f"动作类型未登记分类: {t}，已按失败处理", app_name, "WARN")
            return False
        if t in _VISION_GATED_STEPS:
            res = fn(raw, app_name, allow_vision=allow_vision)
        else:
            res = fn(raw, app_name)
        return self._check_return(t, cat, res, app_name)

    def _check_return(self, t: str, cat: str, res, app_name: str) -> bool:
        """按类别校验返回值契约。None 只在允许它的类别里算成功。

        为什么不再统一 `None -> True`：那会让"根本没判断"与"判断通过"同义。
        例如 `_step_click_point` 丢了 `_verify_landing` 的返回值时，
        落地失败（False）在调用方看来和成功一样，报告因此长期失真。
        """
        allowed = _RETURN_CONTRACT.get(cat) or {"bool"}
        if res is None:
            if "none" in allowed:
                return True
            self.recorder.log(
                f"返回值契约违反: {t}({cat}) 返回 None，按失败处理", app_name, "WARN")
            return False
        if isinstance(res, bool):
            return res
        self.recorder.log(
            f"返回值契约违反: {t}({cat}) 返回 {type(res).__name__}，已按真值折算",
            app_name, "WARN")
        return bool(res)

    def _dispatch(self, act: dict, app_name: str, ritual: bool) -> bool:
        """兼容薄包装（test_diversify_sensor.py:105 直调；B7 后内部走 step/probe）。"""
        if ritual:
            return self._dispatch_step(act, app_name)
        return self._dispatch_probe(act, app_name, allow_vision=True)

    def _step_any_of(self, act, app_name, allow_vision=True):
        """条件分支：按顺序尝试多组动作，第一组**命中**即停。

        为什么需要：App 落地页不确定（开屏广告/活动弹窗/新手引导/上次退出的
        tab/登录态/灰度活动页都会改变落地页）。同一行为的入口可能在首屏、
        也可能只在二级页 ——
          * 写死前置步 → 堵死首屏那条路径；
          * 只写首屏锚点 → 页面漂移时全灭。
        `any_of` 让两条路径共存：先试首屏，没命中再跳「我的」重试。

        choices 中每个 choice 是一串动作；**该串全部动作都返回成功**才算命中。
        注意：分支内的定位动作应写 `optional: false`（默认），
        否则"没找到"会被当成成功，分支立刻终止。

        B7：视觉门控显式参数链 —— 只有最后一个分支 allow_vision=True，
        前面的分支是"便宜的探测"：本机 VLM 图像请求常 90s 超时，
        若探测分支也走视觉兜底，一次 any_of 可能白等好几分钟。
        嵌套（any_of 内的 any_of）时内层用当前 allow_vision 收窄。

        用法：
            - type: any_of
              choices:
              - - {type: click_first, candidates: [{type: text, value: 签到}]}
              - - {type: click_point, x: 0.9, y: 0.915, optional: true}
                - {type: think}
                - {type: click_first, candidates: [{type: text, value: 签到}]}
              optional: true      # 全部分支都没命中时是否放行
        """
        choices = act.get("choices") or []
        if not choices:
            self.recorder.log("any_of 动作缺少 choices，已忽略", app_name, "WARN")
            return False
        n = len(choices)
        for i, chosen in enumerate(choices):
            steps = chosen if isinstance(chosen, list) else [chosen]
            branch_vision = (i == n - 1) and allow_vision
            ok = True
            for a in steps:
                try:
                    if not self._dispatch_probe(a, app_name,
                                                allow_vision=branch_vision):
                        ok = False
                        break
                except StepError as e:
                    self.recorder.log(f"any_of 分支#{i + 1} 步骤失败: {e}",
                                      app_name, "DEBUG")
                    ok = False
                    break
            if ok:
                self.recorder.log(f"any_of 分支#{i + 1}/{n} 命中",
                                  app_name, "DEBUG")
                return True
            self.recorder.log(f"any_of 分支#{i + 1}/{n} 未命中", app_name, "DEBUG")
        if act.get("optional", False):
            # 2026-10-29 契约修正：日志一直写"放行"，代码却 return False，
            # 于是 optional 的 any_of 全 miss 仍被外层记成"步骤失败"，
            # 体检报告的红黄绿因此失真。放行就是成功，返回值必须与日志同义。
            self.recorder.log("any_of 全部分支未命中，optional 放行", app_name, "WARN")
            return True
        # B6：全 miss 非 optional 不再抛 StepError，记 WARN 返回 False
        self.recorder.log("any_of 全部分支均未命中", app_name, "WARN")
        return False

    def _step_random(self, act, app_name, allow_vision=True):
        """行为分支随机化：choices 中随机择一执行。
        每个 choice 可以是单个动作 dict，或一串动作 list。

        2026-10-29 契约修正：原实现不返回任何值（None），子步骤失败被静默吞掉，
        整步在 `_run_kind` 里因 None->True 一律算成功。现在汇总子步骤：
        任一子步骤失败即 False；子步骤抛 StepError 也记 False（不向上抛，
        与 any_of 分支内的处理保持一致）。
        """
        choices = act.get("choices") or []
        if not choices:
            self.recorder.log("random 动作缺少 choices，已忽略", app_name, "WARN")
            return False
        chosen = random.choice(choices)
        steps = chosen if isinstance(chosen, list) else [chosen]
        ok = True
        for a in steps:
            try:
                if not self._dispatch_probe(a, app_name, allow_vision=allow_vision):
                    ok = False
            except StepError as e:
                self.recorder.log(f"random 分支步骤失败: {e}", app_name, "DEBUG")
                ok = False
        return ok

    # ---- 统一点击原语（2026-10-25 整理）----
    # click_text / click_id / click_desc 原本是同一段 20 行代码的三份拷贝，
    # 只有 selector 前缀和日志措辞不同 —— 改一处忘两处（B6「未命中不抛
    # StepError」的修正当年就只打进了 click_text）。现合并为 _step_click
    # 一份实现；旧 type 名保留为别名，老配置/老测试无需改写。
    # 每项：(act 字段名, 日志动词, 失败措辞, 视觉兜底 tag 前缀)
    _CLICK_KINDS = {
        "text": ("text", "点击文本", "未找到文本按钮", "click_text"),
        "id":   ("res_id", "点击控件", "未找到控件 id", "click_id"),
        "desc": ("desc", "点击描述", "未找到描述按钮", "click_desc"),
    }

    def _step_click(self, act, app_name, allow_vision=True):
        """统一点击原语：`by` 选选择器（text 默认 / id / desc），点中返回 True。

        知识库候选 + 视觉兜底的行为与旧 click_text 完全一致；
        B6：未命中不再抛 StepError，detail 写入 `_last_fail` 并返回 False。
        """
        by = str(act.get("by") or "text").lower()
        spec = self._CLICK_KINDS.get(by)
        if spec is None:
            self.recorder.log(f"未知 click by: {by}，已忽略", app_name, "WARN")
            self._last_fail = f"未知 click by: {by}"
            return False
        field, verb, fail_word, tag = spec
        value = act.get(field, "")
        primary = f"{by}={value}"
        obj, has_entry, attempted = self._locate_with_kb(
            app_name, primary, act.get("timeout", 6))
        if obj is not None:
            self._click_tracked(
                obj, app_name, primary, has_entry,
                f"{verb}: {value}",
                # StaleObject 自救：点击前元素失效时按同 selector 重定位
                relocate=lambda: self._locate_with_kb(app_name, primary, 2.0)[0])
            return True
        if self._vision_or_miss(act, app_name, f"{tag}[{value}]",
                                allow_vision=allow_vision):
            return True
        self._last_fail = f"{fail_word}: {value}"
        return False

    def _step_click_point(self, act, app_name):
        # 若本步绑定了图片/VLM 定位，优先用视觉兜底定位（应对布局/分辨率变化）。
        # `vision: false` 可显式关闭视觉兜底 —— 用于「导航到我的」这类
        # **每个行为都要跑**的固定步骤：本机 VLM 图像请求常 90s 超时，
        # 而比例坐标已被 18 个 App 实机验证可靠，走视觉只会白白拖慢且更不稳。
        if act.get("vision", True) and (
                act.get("images") or act.get("template")
                or act.get("vlm_prompt") or act.get("prompt")):
            # desc 里带的是作者写的人类语义（如「签到弹窗『立即领取』」）。把它带进
            # 视觉兜底日志，才能让「签到按钮确实被点过」这句话在日志里被复核到 ——
            # 否则模板命中只留一句 click_point[visual]，事后无法证明点的是签到按钮
            # （2026-10-25 用户判定规则：复核过点击才算签到成功）。
            vdesc = (f"click_point[{act['desc']}]" if act.get("desc")
                     else "click_point[visual]")
            if self._vision_click(act, app_name, vdesc):
                # 2026-10-24：视觉兜底命中后同样要校验落地（原先直接 return 跳过了 expect）。
                # 2026-10-29：校验结果必须**返回**，不能只调用 —— 落地失败要能传上去。
                if act.get("expect"):
                    return self._verify_landing(act, app_name)
                return True
        wh = win_wh(self.d)
        x, y = float(act.get("x")), float(act.get("y"))
        if wh and x <= 1.0 and y <= 1.0:
            x, y = int(wh[0] * x), int(wh[1] * y)
        x, y = self.human.jitter_point(int(x), int(y))
        if self.dry_run:
            return True
        # F2：统一点击入口（误触-回退/限流长停），替代裸 d.click
        self.human.tap(self.d, x, y)
        self.recorder.log(f"点击坐标: ({x},{y})", app_name)
        # 2026-10-23 落地校验：坐标是盲点（拼多多圆形入口偏 80px 就静默走错页），
        # 点完必须验证「落到了预期页面」。多信号投票见 landing.py。
        # 2026-10-29：返回值契约 —— True=落地通过，False=落地失败，None=无可判信号。
        if act.get("expect"):
            return self._verify_landing(act, app_name, x, y)
        return True

    def _verify_landing(self, act, app_name, x=None, y=None, no_retry=False):
        """按 act['expect'] 做多信号落地校验；失败可重试（expect.retry）。

        2026-10-23 真机修正：校验截图必须等页面落定。拼多多实测——点击圆形入口后
        立即（3s 内）截图，整页 dHash 距离 31（过渡动画帧）；等 1.5s 后同一页面距离 3。
        所以每轮先 sleep settle（逐轮加倍），失败再考虑重点击。

        no_retry=True：只探一次、不重复点击（用于 click_first 的「弱命中」探测，
        避免为了验证一个猜测的候选而乱点）。
        """
        import landing
        import time as _time
        expect = act.get("expect") or {}
        retries = 0 if no_retry else int(expect.get("retry", 0) or 0)
        settle = float(expect.get("settle", 1.5))
        for attempt in range(retries + 1):
            if not self.dry_run:
                _time.sleep(settle * (attempt + 1))
            try:
                img = self.d.screenshot()
            except Exception as exc:  # noqa: BLE001
                self.recorder.log(f"落地校验跳过: 截图失败 {type(exc).__name__}",
                                  app_name, "WARN")
                return None
            xml = None
            try:
                xml = self.d.dump_hierarchy()
            except Exception:  # noqa: BLE001 - 节点不可用不影响图形信号
                xml = None
            try:
                pkg = (self.d.app_current() or {}).get("package")
            except Exception:  # noqa: BLE001
                pkg = None
            res = landing.check_landing(img, expect, xml=xml, pkg=pkg)
            tag = landing.describe(res["signals"])
            if res["ok"] is None:
                self.recorder.log(f"落地校验: 无可判信号（{tag}）", app_name, "DEBUG")
                return None
            if res["ok"]:
                self.recorder.log(f"落地校验通过: {tag}", app_name)
                return True
            self.recorder.log(f"落地校验失败（第{attempt + 1}次）: {res['reason']} | {tag}",
                              app_name, "WARN")
            if attempt < retries and x is not None and y is not None and not self.dry_run:
                self.human.tap(self.d, x, y)
                self.recorder.log(f"落地校验重试点击: ({x},{y})", app_name)
        return False

    def _expand_kb_pool(self, app_name, pool, primary):
        """R1：查知识库并把 kb 推荐 selector 展开去重追加到 pool；无可用候选返回 False。

        kb_cands 逐个 _parse_sel，按 (k, v) 去重追加 (k, v, primary if has_entry else None)。
        无知识库记录时 kb_cands=[primary] 正常入池且 primary=None（原语义）；
        记录已 disabled 时 kb_cands=[] 返回 False（调用点跳过该候选）。
        """
        kb_cands, has_entry = self._kb_candidates(app_name, primary)
        if not kb_cands:
            return False
        for sel in kb_cands:
            k, v = _parse_sel(sel)
            if (k, v) not in [(p[0], p[1]) for p in pool]:
                pool.append((k, v, primary if has_entry else None))
        return True

    def _step_click_first(self, act, app_name, allow_vision=True):
        """依次尝试多个候选，点中第一个存在的；每个候选先查知识库（disabled 跳过）。"""
        pool = []           # [(kind, value, primary)]，primary 为知识库主 selector
        for cand in act.get("candidates", []) or []:
            kind, value = cand.get("type"), cand.get("value", "")
            if not value:
                continue
            if not self._expand_kb_pool(app_name, pool, f"{kind}={value}"):
                continue    # 知识库 disabled 的候选直接跳过
        # 记录「作者显式写的候选」数量：合并全局词表后，只有这部分值得给满 2s 定位超时。
        explicit_count = len(pool)
        # 第5步（AUTOP-SELFSEARCH-2026-10-20）：全局词表自搜寻，并入池排在显式之后。
        # 第3项（AUTOP-NL-2026-10-22）：未写 candidates_from 时按当前行为自动推断类别，
        # 使「只写 3 个候选词」的配置也能吃到全 App 共性词表。
        from_ = act.get("candidates_from")
        if not from_:
            from_ = category_for_intent(getattr(self, "_current_bid", ""))
        if from_:
            try:
                merged = candidates_for(from_, {"extra_candidates": self._app_extras(app_name)})
            except ValueError:
                merged = []
                self.recorder.log(f"未知 candidates_from: {from_}，已忽略", app_name, "WARN")
            except Exception:
                merged = []
            for w in merged:
                if not w:
                    continue
                if ("text", w) in [(p[0], p[1]) for p in pool]:
                    continue
                if not self._expand_kb_pool(app_name, pool, "text=" + w):
                    continue
        zone = act.get("zone")
        scroll_left = int(act.get("scroll_retry", 0))
        # 2026-10-23 真机实测修正（性能回归）：
        # 第 3 项把全局词表并进 pool 后，候选数从 ~12 涨到 ~45，
        # 而每个候选原本各给 2s 定位超时 → 单跳最坏 45×2=90s，
        # 重 App（页面未就绪时全 miss）直接吃满 150s 超时，17 个 App 全 TIMEOUT。
        # 现在：显式候选（作者精选）仍给 2s；合并来的全局词只给 0.35s 探针；
        # 整跳再加一个总预算上限，避免候选池膨胀拖垮整条链。
        explicit_n = explicit_count
        probe_fast = 0.35
        budget = max(30.0, explicit_n * 2.0 + 10.0)   # 显式候选要够用，全局词只吃剩余预算
        t_start = time.time()
        while True:
            for i, (k, v, prim) in enumerate(pool):
                if time.time() - t_start > budget:
                    break
                per = 2.0 if i < explicit_n else probe_fast
                res = self._locate(k, v, timeout=per, **({"zone": zone} if zone else {}))
                if res.hit:
                    # 2026-10-24 修正「全局词表劫持」：
                    # 显式候选（作者精选）命中即算数；合并进来的全局词只是「宽泛猜测」，
                    # 命中不等于语义正确（实测三次踩坑：任务中心→立即签到、任务→首页、
                    # 立即签到→现金）。
                    # 规则：本步声明了 expect（=明确知道该落在哪一页）时，只允许显式候选点击，
                    # 弱命中直接跳过继续找 —— 因为点错页面的代价远大于这一步不点。
                    if act.get("expect") and i >= explicit_n:
                        self.recorder.log(
                            f"跳过弱命中({k}){v}（本步有落地校验，只认显式候选）",
                            app_name, "DEBUG")
                        continue
                    obj = res.obj
                    if prim:
                        self.knowledge.mark_ok(app_name, prim)
                    if not self.dry_run:
                        # StaleObject 自救：按同 (kind, value) 重定位再点。
                        self._click_obj(obj, relocate=lambda: self._relocate_candidate(k, v))
                    self.recorder.log(f"多候选命中并点击: ({k}){v}", app_name)
                    # 2026-10-24：click_first 点中后同样做落地校验（与 click_point 一致），
                    # 否则「点中了 A 却落在 B」仍然无声无息。
                    # 2026-10-29：校验结果必须**返回**，不能只调用 —— 与 _step_click_point
                    # 的同类修复对齐。此前丢了返回值，「点中了 A 却落在 B」仍记成功。
                    if act.get("expect"):
                        return self._verify_landing(act, app_name)
                    return True
            # 本轮全未命中：按 scroll_retry 次数翻页重试（自搜寻拓展）
            if scroll_left > 0:
                scroll_left -= 1
                self.human.natural_swipe(self.d)
                self.human.think()
                continue
            break
        # 全失败：回写本次尝试过（有知识库记录）的主 selector 失败计数
        self._kb_mark_fail(app_name, [p[2] for p in pool])
        if self._vision_or_miss(act, app_name, "click_first[all-candidates]",
                                allow_vision=allow_vision):
            return True
        if act.get("optional", False):
            # optional：候选全部未出现 —— 这里**必须返回 False**，不能"放行"。
            # 原因：click_first 最常见的用法是当 any_of 的**分支**，而 any_of 判
            # 「分支是否命中」的依据就是这个返回值（见 _step_any_of docstring：
            # 「分支内的定位动作应写 optional: false，否则"没找到"会被当成成功，
            # 分支立刻终止」）。若这里返回 True，any_of 会在第 1 个分支就收工，
            # 后续"跳到我的再试一次"的兜底分支永远不执行 —— any_of 形同虚设。
            # 2026-10-29：原日志写"optional 放行"，与返回值相反，读日志的人会以为
            # 这步没算失败。改成如实描述，避免再次误导体检结论。
            self.recorder.log(
                f"候选全部未出现，optional 仅抑制告警（返回值仍为 False，"
                f"any_of 分支依赖此语义）: {act.get('candidates')}", app_name, "WARN")
            return False
        # B6：非 optional 未命中不再抛 StepError，detail 写入 _last_fail 返回 False
        self._last_fail = f"所有候选均未出现: {act.get('candidates')}"
        return False

    def _step_swipe(self, act, app_name):
        # 2026-10-25 修 bug（抖音火山版校准实测踩到）：natural:true 曾经**忽略
        # from/to** 且永远向下滑 —— human.natural_swipe 内部自己随机起终点，
        # 想把「向上滑回顶」写成 natural:true，结果连滑到底，预约行被推得更远。
        # 现在：给了 from/to 就按坐标走人类轨迹（与普通 swipe 同一条轨迹链）；
        # 只有省略 from/to 时才保留旧的「随机自然滑动」语义（recorder 录制的
        # swipe_natural 走这条，行为不变）。
        f, t = act.get("from"), act.get("to")
        if act.get("natural", False) and self.d and not (f and t):
            self.human.natural_swipe(self.d)
            self.recorder.log("自然滑动(随机)", app_name)
            return
        wh = win_wh(self.d)
        f, t = act.get("from"), act.get("to")
        if not (f and t and wh):
            raise StepError("swipe 需要 from/to 坐标")
        pct = lambda v: (  # noqa: E731
            int(wh[0] * v[0]), int(wh[1] * v[1])
        ) if v[0] <= 1.0 and v[1] <= 1.0 else (int(v[0]), int(v[1]))
        sx, sy = pct(f)
        ex, ey = pct(t)
        dur = float(act.get("duration", 0.6))
        if not self.dry_run:
            # 曲线轨迹优先：所有 swipe 都走人类轨迹注入（途中小幅抖动 + 变速）
            # 仅当 act 显式要求直线（straight=true）或设备异常时回退原生 swipe
            if not act.get("straight", False):
                points, intervals = self.human.trajectory.generate_gesture(
                    (sx, sy), (ex, ey))
                ok = self.human.trajectory.inject_touch(self.d, points, intervals)
                if ok:
                    self.recorder.log(
                        f"滑动(轨迹) ({sx},{sy})->({ex},{ey})", app_name)
                    return
            self.d.swipe(sx, sy, ex, ey, duration=dur)
        self.recorder.log(f"滑动 ({sx},{sy})->({ex},{ey})", app_name)

    def _step_swipe_natural(self, act, app_name):
        """兼容别名（2026-10-25 合并）：等价于 swipe + natural:true。

        省略 from/to → 随机自然滑动（recorder 录制流走这条）；
        带 from/to → 按坐标走人类轨迹（旧实现本就支持，现由 _step_swipe 统一）。
        """
        return self._step_swipe(dict(act, natural=True), app_name)

    def _step_captcha(self, act, app_name):
        """验证码处理原语：检测滑块 -> 缺口识别 -> 拟人拖拽求解。

        act.mode: slider(默认) | 预留。滑块未出现时静默跳过（视为无需处理）。
        """
        if self.captcha is None:
            if not act.get("optional", False):
                self.recorder.log("验证码处理未启用（captcha.enabled=false 或依赖缺失），跳过",
                                  app_name, "WARN")
            return
        if self.dry_run:
            self.recorder.log("[dry-run] 将检测并处理滑块验证码", app_name)
            return
        if self.d is None:
            return
        dump = self._dump_safe()
        screen = self.captcha._screenshot(self.d)
        if not self.captcha.detect_slider(self.d, screen, dump):
            self.recorder.log("未检测到滑块验证码，跳过", app_name, "DEBUG")
            return
        self.recorder.log("检测到滑块验证码，开始求解", app_name)
        ok = self.captcha.solve(self.d, app=app_name, screen_img=screen, dump=dump)
        if not ok:
            # F2 反检测：验证码求解失败 = 风控命中信号。会话级冷却后再让
            # 上层决定去向，期间绝不重试猛点（冷却秒数记入日志）。
            cd = self.human.captcha_cooldown()
            if cd:
                self.recorder.log(
                    f"验证码失败，会话冷却 {cd:.0f}s（期间不重试）",
                    app_name, "WARN")
            raise StepError(f"滑块验证码求解失败（{self.captcha.retry_times} 次尝试）")
        self.human.think()

    def _relocate_candidate(self, k, v):
        """元素失效重定位（StaleObject 竞态自救）：按原 (kind, value) 再找一次。

        返回新元素或 None；任何 RPC 异常都吞掉返回 None（让上层走
        「步骤失败」路径，不崩）。见 locator._click_obj 坑位2。
        """
        try:

"""locator.py - 元素定位层（D 批从 executor.py 三分拆）

搬迁来源：executor.py 的 Executor 类 —— _locate（L480-525）、_label_of

_click_tracked（L657-666）、_vision_or_miss（L668-675）、_vision_click
（L677-716）；模块级 LocateResult（L56-68）、_parse_sel（L36-44）。

坑位注释原文照搬，禁止润色（见各方法 docstring）。

方法体内通过 `self._xxx` 同名可覆盖入口互相调用：本类被 executor.py 门面
多继承后，self 是 Executor 实例，tests 对 Executor 实例打桩仍然生效。
"""
from dataclasses import dataclass

try:
    from pick_locate import pick_best
except ImportError:  # pragma: no cover - 未拷贝 pick_locate.py 时退化为本地兜底
    pick_best = None


def _parse_sel(sel):
    """把知识库 selector 拆成 (kind, value)：'text=每日签到' -> ('text','每日签到')。"""
    sel = str(sel)
    if "=" in sel:
        kind, _, value = sel.partition("=")
        if kind.strip().lower() in ("text", "id", "desc"):
            return kind.strip().lower(), value.strip()
    return "text", sel


@dataclass
class LocateResult:
    """元素定位结果（B6 显式化）。

    - hit=False 表示「未命中」：等待超时、pick_best 拒配、kind 非法等；
      定位类动作**永不**因未找到而抛异常，由上层据 hit 记「步骤失败」。
    - detail 复用原 raise 消息文本（零日志漂移），供 `_run_actions` 记录。
    """
    hit: bool
    obj: object = None
    detail: str = "未找到元素"


class Locator:
    """元素定位层：_locate/_pick_best、元素知识库辅助、视觉兜底回退链。"""

    def _locate(self, kind, value, timeout=6.0, zone=None, screen_w=0):
        """定位元素，返回 LocateResult(hit, obj, detail)。

        坑位记录：`textContains` 会命中"长文案里恰好包含关键词"的节点。
        实测一淘"我的"页里，候选 `签到` 唯一命中的是 FAQ 链接
        「什么是签到领钱，如何参加？」——若直接点下去就点错了。
        因此这里做两步：先取全部匹配并按"更短/可点击/完全相等"择优，
        再把明显过长的非可点击文本判为"未命中"，交给下一个候选或视觉兜底。

        B6：定位失败不再抛异常，统一返回 hit=False 的 LocateResult。
        第3步：zone/screen_w 位置先验透传 _pick_best（多匹配时按区加分）。
        """
        # dry-run / 未连接设备：不 import uiautomator2，直接返回未命中
        if self.d is None or self.dry_run:
            return LocateResult(False, None, "dry-run 或未连接设备，跳过定位")
        import uiautomator2 as u2  # noqa
        d = self.d
        value = str(value)
        if kind == "text":
            obj = d(textContains=value)
        elif kind == "id":
            obj = d(resourceId=value)
        elif kind == "desc":
            obj = d(descriptionContains=value)
        else:
            return LocateResult(False, None, f"未知定位类型: {kind}")
        if not obj.wait(timeout=timeout):
            return LocateResult(False, None, "等待超时，元素未出现")
        best = self._pick_best(obj, value, kind, zone=zone, screen_w=screen_w)
        if best is None:
            return LocateResult(False, None, "候选拒配（长文案误命中，视为未命中）")
        return LocateResult(True, best, "")

    @staticmethod
    def _label_of(info, kind):
        if kind == "text":
            return info.get("text") or ""
        if kind == "desc":
            return info.get("contentDescription") or ""
        return info.get("resourceId") or ""

    def _pick_best(self, obj, target, kind, zone=None, screen_w=0):
        """从多匹配里择优；对"长文案误命中"做拒配。

        第3步：zone/screen_w 位置先验 —— 多匹配时按底部带/右上/右缘加分，
        未命中者扣分（仅用于择优，不硬过滤）；缺坐标或未知屏尺寸则中性。
        """
        try:
            n = int(getattr(obj, "count", 1))
        except Exception:
            return obj
        try:
            if n <= 1:
                info = obj.info
                entries = [{
                    "label": self._label_of(info, kind),
                    "clickable": bool(info.get("clickable")),
                    "top": int(info["bounds"]["top"]) if info.get("bounds") else 0,
                    "left": int(info["bounds"]["left"]) if info.get("bounds") else None,
                    "right": int(info["bounds"]["right"]) if info.get("bounds") else None,
                }]
                screen_h = 0
            else:
                try:
                    d_info = self.d.info or {}
                    screen_h = int(d_info.get("displayHeight") or 0)
                    if not screen_w:
                        screen_w = int(d_info.get("displayWidth") or 0)
                except Exception:
                    screen_h = 0
                entries = []
                for i in range(min(n, 12)):
                    try:
                        info = obj[i].info
                        entries.append({
                            "label": self._label_of(info, kind),
                            "clickable": bool(info.get("clickable")),
                            "top": int(info["bounds"]["top"]) if info.get("bounds") else 0,
                            "left": int(info["bounds"]["left"]) if info.get("bounds") else None,
                            "right": int(info["bounds"]["right"]) if info.get("bounds") else None,
                        })
                    except Exception:
                        continue
        except Exception:
            return obj
        if pick_best is None:
            return obj
        idx = pick_best(entries, str(target), kind, screen_h, self.recorder.log,
                        screen_w=screen_w, zone=zone)
        if idx is None:
            return None
        return obj if n <= 1 else obj[idx]

    def _click_obj(self, obj, relocate=None):
        """点击元素中心（经 human.tap：抖动+误触回退+限流）。

        坑位1（2026-10-21 回归实崩）：u2 的 UiObject **没有 `.rect` 属性**，
        正确 API 是 `.bounds()` -> `(lx, ly, rx, ry)` plain tuple。旧代码
        `obj.rect` + `.left/.right` 双重错误 —— 只要文案命中走到真实点击
        （click_first/scroll_to）就必崩 `AttributeError`。一轮回归 7 个「命中」
        全是坐标兜底（文案先 miss 所以没走到这里），把此坑完全遮住了。

        坑位2（2026-10-21 三轮回归实崩）：`StaleObjectException` ——
        元素定位后页面变化，`obj.bounds()` 抛 RPCUnknownError 直接崩掉
        整条流程。u2 元素引用是定位时快照，点击前必须容忍失效：
        relocate 回调重定位一次再点；仍失效抛 StepError（上层记
        「步骤失败」继续跑，不崩）。

        兼容分支：测试/探针里的假元素带 `.rect` 属性对象。
        """
        lx = ly = rx = ry = None
        for attempt in (0, 1):
            try:
                rect = getattr(obj, "rect", None)
                if rect is not None and hasattr(rect, "left"):
                    lx, ly, rx, ry = rect.left, rect.top, rect.right, rect.bottom
                else:
                    lx, ly, rx, ry = obj.bounds()
                break
            except Exception as e:  # noqa: BLE001 - u2 RPC 错误族统一按失效处理
                if attempt == 0 and relocate is not None:
                    fresh = relocate()
                    if fresh is not None and fresh is not obj:
                        obj = fresh
                        continue
                from behavior_runner import StepError
                raise StepError(
                    f"点击前元素已失效（{e.__class__.__name__}，页面可能已变化）")
        cx = (lx + rx) // 2
        cy = (ly + ry) // 2
        x, y = self.human.jitter_point(cx, cy)
        if self.dry_run:
            return
        self.human.tap(self.d, x, y)

    # ---------- 元素知识库辅助 ----------
    def _kb_candidates(self, app_name, primary_selector):
        """先查知识库，返回本元素当前应尝试的候选 selector 列表与是否命中知识库记录。

        返回 (cands, has_entry)：
          - 无知识库记录   -> ([primary_selector], False)，走原逻辑；
          - 记录已 disabled -> ([], True)，跳过元素定位直接转视觉兜底；
          - 有记录且启用   -> ([主] + [启用 alternatives], True)，含替代轮换。
        """
        if self.knowledge is None:
            return [primary_selector], False
        if not self.knowledge.has_element(app_name, primary_selector):
            return [primary_selector], False
        return self.knowledge.candidate_selectors(app_name, primary_selector), True

    def _kb_mark_fail(self, app_name, primaries):
        """对本次实际尝试过、知识库中有记录的主 selector 做失败回写。"""
        if self.knowledge is None:
            return
        seen = []
        for p in primaries:
            if p and p not in seen:
                seen.append(p)
                self.knowledge.mark_fail(app_name, p)

    def _locate_with_kb(self, app_name, primary, timeout=6):
        """查知识库并尝试候选定位；返回 (obj, has_entry, attempted)。

        - 无知识库记录           -> 只用主 selector 定位，has_entry=False；
        - 记录已 disabled        -> cands 为空，attempted=False，跳过元素定位；
        - 有记录且启用           -> 依次尝试主 + 启用 alternatives。
        失败回写 mark_fail 遵循「仅当 has_entry and cands（实际尝试过才计数）」。
        """
        cands, has_entry = self._kb_candidates(app_name, primary)
        attempted = bool(cands)
        if cands:  # 空列表=知识库已 disabled，跳过元素定位直接转视觉
            for sel in cands:
                k, v = _parse_sel(sel)
                res = self._locate(k, v, timeout)
                if res.hit:
                    return res.obj, has_entry, attempted
        if has_entry and attempted:
            self.knowledge.mark_fail(app_name, primary)
        return None, has_entry, attempted

    def _click_tracked(self, obj, app_name, primary, has_entry, log_text,
                       relocate=None):
        """命中分支共享件：知识库 mark_ok + 真人化点击 + 日志。

        relocate：元素失效（StaleObject）时的重定位回调，透传 _click_obj。
        """
        if has_entry:
            self.knowledge.mark_ok(app_name, primary)
        if not self.dry_run:
            self._click_obj(obj, relocate=relocate)
        self.recorder.log(log_text, app_name)

    def _vision_or_miss(self, act, app_name, desc, allow_vision=True):
        """未命中分支共享件：按开关尝试视觉兜底，命中返回 True。"""
        if allow_vision and self._vision_click(act, app_name, desc):
            return True
        return False

    # ---------- 视觉兜底定位回退链 ----------
    def _vision_click(self, act, app_name, desc) -> bool:
        """在 uiautomator2 元素定位失败/超时后，尝试视觉兜底点击。

        回退顺序：
          1) act 中绑定的 images/template 图片资源 -> OpenCV 模板匹配点击
          2) 若配置开启且 vlm 已配置 -> VisionLocator 的 VLM 后端识别点击
        命中则执行真人化点击并写日志，返回 True；否则返回 False。
        """
        if not self.vision or not self.vision_enabled:
            return False
        templates = act.get("images") or []
        if act.get("template"):
            templates = [act["template"]] + list(templates) if not isinstance(

def dhash(img, size: int = 8) -> int:
    """差值哈希（64bit 整数）。抗压缩、抗轻微缩放，对布局变化敏感。"""
    g = img.convert("L").resize((size + 1, size))
    px = list(g.getdata())
    bits = 0
    for row in range(size):
        base = row * (size + 1)
        for col in range(size):
            bits = (bits << 1) | (1 if px[base + col] > px[base + col + 1] else 0)
    return bits


def hamming(a: int, b: int) -> int:
    return bin(a ^ b).count("1")


def _read_gray(path: str):
    """读灰度图。必须用 np.fromfile+imdecode：cv2.imread 在 Windows 上读不了
    含中文的路径（本项目所有模板都在 images/<中文App名>/ 下）。"""
    if cv2 is None or not os.path.isfile(path):
        return None
    try:
        data = np.fromfile(path, dtype=np.uint8)
    except Exception:  # noqa: BLE001
        return None
    if data.size == 0:
        return None
    return cv2.imdecode(data, cv2.IMREAD_GRAYSCALE)


def template_score(screen, tpl_path: str) -> float | None:
    """参考小图在实时截图中的最佳匹配度（0~1）。缺 cv2 / 文件不存在 / 模板近乎均匀 → None。

    2026-10-23 修正：TM_CCOEFF_NORMED 对**方差≈0 的均匀模板会退化成恒等于 1**
    （实测 40x40 纯白模板在灰屏上得 1.0），这种模板提供不了任何判别信息，
    必须判为「不适用」而不是高分，否则会用假阳性把落地校验变成摆设。
    """
    tpl = _read_gray(tpl_path)
    if tpl is None:
        return None
    if float(tpl.std()) < 5.0:          # 近乎纯色：无判别力
        return None
    scr = cv2.cvtColor(np.array(screen.convert("RGB")), cv2.COLOR_RGB2GRAY)
    if tpl.shape[0] > scr.shape[0] or tpl.shape[1] > scr.shape[1]:
        return 0.0
    res = cv2.matchTemplate(scr, tpl, cv2.TM_CCOEFF_NORMED)
    return float(res.max())

# 参考图与实时截图都先归一到这个尺寸再算 dHash，否则分辨率/缩放差异会
# 把「同一页面」算成「不同页面」（实测同页 JPEG 重压缩距离 0，跨页 12~33，
# 阈值取 8 有干净间隔；这是拼多多白底卡片页唯一可靠的判别信号）。
PHASH_SIZE = (240, 520)


def _norm(im):
    return im.convert("RGB").resize(PHASH_SIZE)


def _crop_norm(im, region):
    """按归一化 region [x1,y1,x2,y2] 裁剪后再归一到统一尺寸。

    整页 dHash 会被业务状态干扰（实测：签到前/签到后同页距离 23~31，超过阈值 8），
    而页头等稳定区域不受影响。所以参考图与实时截图必须裁同一区域再比。
    """
    im = im.convert("RGB")
    if region and len(region) == 4:
        w, h = im.size
        box = (int(region[0] * w), int(region[1] * h),
               int(region[2] * w), int(region[3] * h))
        box = (max(0, box[0]), max(0, box[1]), min(w, box[2]), min(h, box[3]))
        if box[2] > box[0] and box[3] > box[1]:
            im = im.crop(box)
    return im.resize(PHASH_SIZE)

def check_landing(screen, expect: dict, xml: str | None = None,
                  pkg: str | None = None, activity: str | None = None,
                  base_dir: str | None = None) -> dict:
    """按 expect 逐信号校验，返回 {ok, signals, reason, score}。

    ok: True 通过 / False 失败 / None 全部跳过（无法判断，不阻断）
    """
    expect = expect or {}
    base = base_dir or _ROOT
    signals: dict[str, object] = {}

    # S1 文案（节点）
    want = [str(w) for w in (expect.get("text_any") or []) if str(w).strip()]
    if want:
        texts = _node_texts(xml)
        joined = " ".join(texts)
        hit = [w for w in want if w in joined]
        signals["text_nodes"] = bool(hit)
        signals["_text_hit"] = hit
    forbid = [str(w) for w in (expect.get("text_none") or []) if str(w).strip()]
    if forbid:
        joined = " ".join(_node_texts(xml))
        bad = [w for w in forbid if w in joined]
        signals["text_forbidden"] = (not bad)
        signals["_text_bad"] = bad

    # S2 图形模板
    tpl = expect.get("template")
    if tpl:
        path = tpl if os.path.isabs(tpl) else os.path.join(base, tpl)
        score = template_score(screen, path)
        if score is None:
            signals["template"] = None
        else:
            thr = float(expect.get("template_threshold", 0.75))
            signals["template"] = score >= thr
            signals["_template_score"] = round(score, 3)

    # S3 感知哈希（支持 phash_region 只 hash 稳定区域，避开业务状态变化）
    ref = expect.get("phash")
    if ref:
        path = ref if os.path.isabs(ref) else os.path.join(base, ref)
        if os.path.isfile(path):
            from PIL import Image
            region = expect.get("phash_region")
            screen_img = _crop_norm(screen, region)
            with Image.open(path) as im:
                ref_img = _crop_norm(im.convert("RGB"), region)
            dist = hamming(dhash(screen_img), dhash(ref_img))
            max_d = int(expect.get("phash_max_dist", 8))
            signals["phash"] = dist <= max_d
            signals["_phash_dist"] = dist
        else:
            signals["phash"] = None

    # S4 结构
    if expect.get("min_nodes") is not None:
        n = (xml or "").count("<node")
        signals["min_nodes"] = n >= int(expect["min_nodes"])
        signals["_nodes"] = n
    if expect.get("max_nodes") is not None:
        n = (xml or "").count("<node")
        signals["max_nodes"] = n <= int(expect["max_nodes"])
    if expect.get("pkg") and pkg:
        signals["pkg"] = (pkg == expect["pkg"])
    if expect.get("activity_contains") and activity:
        signals["activity"] = (str(expect["activity_contains"]) in activity)

    # S5 OCR（可选）
    if expect.get("ocr_any"):
        got = _ocr_texts(screen)
        if got is None:
            signals["ocr"] = None
        else:
            joined = " ".join(got)
            signals["ocr"] = any(str(w) in joined for w in expect["ocr_any"])

    ran = {k: v for k, v in signals.items()
           if not k.startswith("_") and v is not None}
    if not ran:
        return {"ok": None, "signals": signals, "reason": "无可执行信号（全部跳过）",
                "score": 0.0}

    passed = [k for k, v in ran.items() if v]
    min_pass = expect.get("min_pass")
    if min_pass is None:
        ok = len(passed) == len(ran)
    else:
        ok = len(passed) >= int(min_pass)
    reason = ("通过 " + ",".join(passed)) if ok else \
             ("失败：" + ",".join(k for k in ran if not ran[k]))
    return {"ok": ok, "signals": signals, "reason": reason,
            "score": round(len(passed) / len(ran), 3)}


def describe(signals: dict) -> str:
    """把信号压成一行日志。"""
    parts = []
    for k, v in signals.items():
        if k.startswith("_"):
            continue
        if v is None:
            parts.append(f"{k}=skip")
        else:
            parts.append(f"{k}={'ok' if v else 'FAIL'}")
    for k in ("_text_hit", "_text_bad", "_template_score", "_phash_dist", "_nodes"):
        if k in signals:
            parts.append(f"{k[1:]}={signals[k]}")
    return " ".join(parts)

  * **执行层仍用 step.raw**，所以老配置一行不改、行为零变化；
  * 编译产物可用于：编译期 lint / dry-run 语义投影对拍 / 静态校验。

  ② 视觉锚+兜底   action: click + target{by: image/vision, fallback: (x,y)}

def _xy(act: dict) -> tuple[float, float]:
    """取 (x, y)。**保留原值，绝不取整** —— 0~1 是比例坐标。"""
    try:
        return float(act["x"]), float(act["y"])
    except (KeyError, TypeError, ValueError) as exc:

def _on_miss(act: dict) -> str:
    """optional: false -> fail；其余（含未写）-> skip。

    注意：这是**块级**语义，描述"整个 step 没命中时该不该算失败"。
    它不改变原语的返回值 —— `click_first` 作为 any_of 分支时全 miss 仍返回 False，
    否则 any_of 会在第 1 个分支就收工（见 behavior_runner._step_any_of docstring）。
    """
    return "fail" if act.get("optional") is False else "skip"


def _base(act: dict) -> dict:
    return {"expect": act.get("expect") or None,
            "on_miss": _on_miss(act),
            "label": str(act.get("desc") or "")}


def _fallback_points(act: dict) -> tuple[tuple[float, float], ...]:
    """解析 target.fallback：接受 [[x,y]] / [{"point":[x,y]}] / {"point":[x,y]}。"""
    out: list[tuple[float, float]] = []
    fbs = act.get("fallback")
    if not fbs:
        return ()
    if isinstance(fbs, dict):
        fbs = [fbs]
    for fb in fbs:
        pt = None
        if isinstance(fb, (list, tuple)) and len(fb) == 2:
            pt = (float(fb[0]), float(fb[1]))
        elif isinstance(fb, dict) and "point" in fb:
            v = fb["point"]
            if isinstance(v, (list, tuple)) and len(v) == 2:
                pt = (float(v[0]), float(v[1]))
        if pt is not None:
            out.append(pt)
    return tuple(out)


def _target_from_fields(act: dict, by: str | None = None,
                        value: str | None = None) -> Target:
    """从 act 构造 Target。显式 by/value 优先，否则按字段推断。"""
    if by is None:
        if "text" in act:
            by = "text"
        elif "res_id" in act:
            by = "id"
        elif "desc" in act and act.get("desc"):
            by = "desc"
        elif "value" in act:
            by = "text"
        else:
            raise ValueError(f"action=click 缺少 by 或定位字段: {act!r}")
    by = by.strip().lower()
    if by not in ("text", "id", "desc", "image", "vision"):
        raise ValueError(f"未知 click by: {by!r}")

    if value is None:
        field_name = {"text": "text", "id": "res_id", "desc": "desc",
                      "image": "value", "vision": "value"}[by]
        value = str(act.get(field_name, "") or "")

    pool: list[str] = []
    for v in (act.get("pool") or []):
        pool.append(str(v))
    if not pool:
        # 兼容 candidates 写法（每个 candidate 的 value）
        for c in (act.get("candidates") or []):
            if isinstance(c, dict) and c.get("value"):
                pool.append(str(c["value"]))

    return Target(by=by, value=str(value), pool=tuple(pool),

def _compile_click_point(act: dict) -> Step:
    """click_point 拆两种（任务书 §5.6）。

    注意 x/y **不是必填**：实测 72 个顶层 click_point 里，有 53 个只写 `images`
    没有坐标（纯视觉锚点，命中不了就算未命中，没有兜底可言）。
    只有"既给图像又给坐标"的 8 个才产生 fallback。
    """
    imgs = act.get("images") or ([act["template"]] if act.get("template") else [])
    vlm = act.get("vlm_prompt") or act.get("prompt")
    has_xy = "x" in act and "y" in act
    if imgs or vlm:
        by = "image" if imgs else "vision"
        value = str(imgs[0]) if imgs else str(vlm)
        fb = (_xy(act),) if has_xy else ()
        target = Target(by=by, value=value, fallback=fb,
                        vision=bool(act.get("vision", True)))
        return Step(action="click", target=target, raw=act, **_base(act))
    # 无锚点：必须是纯坐标
    x, y = _xy(act)
    return Step(action="tap", point=(x, y), raw=act, **_base(act))


def _compile_flow(act: dict, flow_name: str, kind: str) -> Step:
    branches: list[tuple[Step, ...]] = []
    if kind == "flow_via_branches":
        # click_first：每个 candidate 一条单步分支
        for c in (act.get("candidates") or []):
            if not isinstance(c, dict):
                continue
            val = str(c.get("value") or "")
            if not val:
                continue
            by = str(c.get("type") or "text").lower()
            by = {"res_id": "id"}.get(by, by)
            if by not in ("text", "id", "desc"):
                continue
            field_name = {"text": "text", "id": "res_id", "desc": "desc"}[by]
            branches.append((Step(action="click",
                                  target=Target(by=by, value=val),
                                  raw={field_name: val, "type": "click_text",
                                       "by": by},
                                  **_base({})),))
    else:
        for ch in (act.get("choices") or []):
            steps = ch if isinstance(ch, list) else [ch]
            branch = tuple(compile_step(a) for a in steps if isinstance(a, dict))
            if branch:
                branches.append(branch)
    # `candidates_from: sign` = 候选由词池在运行期提供，静态 candidates 可以为空。
    # 这是合法写法（实测 2 处：飞猪旅行/米读极速版的 sign 链），不能当配置错误。
    pool_from = None
    if not branches and act.get("candidates_from"):
        pool_from = str(act["candidates_from"])
    return Step(flow=flow_name, branches=tuple(branches), pool_from=pool_from,
                raw=act, **_base(act))


def _compile_action_from_v1(act: dict, name: str, extra: tuple) -> Step:

        return Step(action="swipe", raw=act, **_base(act))
    if name == "press":
        key = extra[0] if extra else "back"
        return Step(action="press", key=key, raw=act, **_base(act))
    if name == "wait":
        secs = None
        if extra and extra[0] == "seconds":
            try:

            except (TypeError, ValueError):
                secs = 1.0

        return Step(action="wait", seconds=secs, raw=act, **_base(act))
    if name == "extract":
        return Step(action="extract", raw=act, **_base(act))
    raise ValueError(f"内部映射错误：旧 type 无法折叠到 action={name!r}")


def _compile_v2_action(act: dict, action: str) -> Step:

    if action == "tap":
        x, y = _xy(act)
        return Step(action="tap", point=(x, y), raw=act, **_base(act))
    if action == "press":
        key = str(act.get("key") or "").strip().lower()
        if key not in ("back", "home"):
            raise ValueError(f"action=press 缺少合法 key（back/home）: {act!r}")
        return Step(action="press", key=key, raw=act, **_base(act))
    if action == "wait":
        secs = act.get("seconds")
        try:
            secs_f = float(secs) if secs is not None else None
        except (TypeError, ValueError):
            secs_f = None
        return Step(action="wait", seconds=secs_f, raw=act, **_base(act))
    if action == "swipe":
        return Step(action="swipe", raw=act, **_base(act))
    if action == "extract":
        return Step(action="extract", raw=act, **_base(act))
    if action == "input":
        return Step(action="input", raw=act, **_base(act))
    raise ValueError(f"未知 action: {action!r}")


# ---------------- 主入口 ----------------

def compile_step(act: dict) -> Step:
    """单个 step dict -> Step。v1（只有 type）与 v2（action/flow/macro）都接受。"""
    if not isinstance(act, dict):
        raise ValueError(f"step 必须是 dict，收到 {type(act).__name__}")

    t = act.get("type")
    a = act.get("action")
    f = act.get("flow")
    m = act.get("macro")

    # 1) 三个主键互斥
    primaries = [x for x in (a, f, m) if x]
    if len(primaries) > 1:
        raise ValueError(f"action/flow/macro 同时出现多个: {primaries!r}")

    # 2) type 与主键并存：只允许"语义等价"的写法，其余一律拒绝（不许猜）
    if t and primaries:
        ok = False
        if a and t == a:
            ok = True
        elif a and LEGACY_TO_V2.get(t, (None,))[0] == "action+field" \
                and LEGACY_TO_V2[t][1] == a:
            ok = True                     # type: click_text + action: click
        elif f and LEGACY_TO_V2.get(t, (None,))[0] in ("flow_via_branches",
                                                       "flow_via_choices") \
                and LEGACY_TO_V2[t][1] == f:
            ok = True                     # type: any_of + flow: first_ok
        elif m and LEGACY_TO_V2.get(t, (None,))[0] == "macro" \
                and LEGACY_TO_V2[t][1] == m:
            ok = True
        if not ok:
            raise ValueError(f"type 与主键冲突: type={t!r} "
                             f"action={a!r} flow={f!r} macro={m!r}")

    # 3) 纯 v2 写法
    if a:
        return _compile_v2_action(act, a)
    if f:
        if f not in FLOW_NAMES:
            raise ValueError(f"未知 flow: {f!r}（合法值 {sorted(FLOW_NAMES)}）")
        return _compile_flow(act, f, "flow_via_choices")
    if m:
        if m not in MACRO_NAMES:
            raise ValueError(f"未知 macro: {m!r}（合法值 {sorted(MACRO_NAMES)}）")
        return Step(macro=m, raw=act, **_base(act))

    # 4) v1 写法
    if not t:
        raise ValueError(f"step 缺少 type 或 action/flow/macro: {act!r}")
    spec = LEGACY_TO_V2.get(t)
    if spec is None:
        raise ValueError(f"未知 type: {t!r}（未在 LEGACY_TO_V2 登记，拒绝静默忽略）")

    kind = spec[0]
    if kind == "action":
        return _compile_action_from_v1(act, spec[1], tuple(spec[2:]))
    if kind == "action+field":
        _, name, fld, by = spec
        target = _target_from_fields(act, by=by, value=str(act.get(fld, "") or ""))
        return Step(action=name, target=target, raw=act, **_base(act))
    if kind in ("flow_via_branches", "flow_via_choices"):
        return _compile_flow(act, spec[1], kind)
    if kind == "click_point":
        return _compile_click_point(act)
    if kind == "macro":
        return Step(macro=spec[1], raw=act, **_base(act))
    if kind == "v2_click":
        return _compile_v2_action(act, "click")
    if kind == "legacy":
        return Step(legacy_type=spec[1], raw=act, **_base(act))
    raise ValueError(f"内部映射错误: type={t!r} spec={spec!r}")


def compile_actions(actions: list) -> list:
    """批量编译。行为可能是 [[..],[..]] 多候选模板，编译后保持两级结构。"""
    if not actions:
        return []
    if all(isinstance(x, list) for x in actions):
        return [compile_actions(grp) for grp in actions]
    return [compile_step(x) for x in actions]

_DEAD_OPTIONAL_TYPES = frozenset({"click_text", "click_id", "click_desc",
                                  "click_point"})


def lint(steps: list, app_name: str = "", behavior: str = "") -> list[dict]:
    """编译期校验。返回 [{level, app, behavior, msg}]。

    ERROR 应阻断（配置写错，跑起来必然静默失败）；WARN/INFO 只提示。
    注意：WARN 不改变任何行为，也不自动改写配置 —— 死字段要人来确认。
    """
    issues: list[dict] = []

    def _add(level: str, msg: str) -> None:
        issues.append({"level": level, "app": app_name,
                       "behavior": behavior, "msg": msg})

    def _walk(items) -> None:
        for s in items:
            if isinstance(s, list):
                _walk(s)
                continue
            if not isinstance(s, Step):
                continue
            if s.legacy_type:
                _add("INFO", f"legacy step 待折叠: type={s.legacy_type}")
            if s.action == "click" and s.target is None:
                _add("ERROR", "action=click 缺少 target")
            if s.target and s.target.by == "image" and not s.target.vision:
                _add("WARN", "by=image 且 vision:false 自相矛盾（锚点永不生效）")
            if s.flow and not s.branches and not s.pool_from:
                _add("ERROR", f"flow={s.flow} 既无 branches 也无 candidates_from")
            if s.pool_from:
                _add("INFO", f"flow={s.flow} 候选由词池动态提供: "
                             f"candidates_from={s.pool_from}")
            raw_t = (s.raw or {}).get("type")
            if raw_t in _DEAD_OPTIONAL_TYPES and "optional" in (s.raw or {}):
                _add("WARN", f"type={raw_t} 上的 optional 是死字段"
                             f"（执行层从不读），批量转 on_miss 会改变行为")
            if s.branches:
                _walk(list(s.branches))

    _walk(steps)
    return issues

# -*- coding: utf-8 -*-
"""test_any_of.py - Executor._step_any_of 单元测试（无需真机）

背景：App 落地页不确定（开屏广告/活动弹窗/新手引导/上次退出的 tab/登录态），
同一行为的入口可能在首屏、也可能只在二级页。写死前置步会堵死首屏路径，
只写首屏锚点又会在页面漂移时全灭。`any_of` 让多条路径共存。

这里覆盖它的关键语义：
  1. 分支按顺序尝试，第一组**全部动作成功**即停，后续分支不执行；
  2. `optional: true` 的定位动作「没找到」返回 False（不是 None/异常），
     必须被识别为分支未命中 —— 否则任何分支都会"成功"，any_of 形同虚设；
  3. 分支内某步抛 StepError → 该分支判失败，且**后续步骤不执行**；
  4. 全部分支未命中时：optional 放行返回 False，否则 WARN 返回 False；
  5. 视觉门控是显式参数链：只有最后一个分支 allow_vision=True
     （B7 教训：早期用 `_probe_no_vision` 实例标志位临时改写再还原，
     异常/新增直调点会留下脏状态，测试只能靠反证用例兜底；现改为
     `allow_vision` 参数显式贯穿，反证用例随之取消）。

运行：
    python tests/test_any_of.py
"""
import os
import sys

from executor import Executor, StepError, LocateResult  # noqa: E402


class _Rec:
    def __init__(self):
        self.lines = []

    def log(self, event, app="", level="INFO"):
        self.lines.append(f"[{level}] {event}")


def _mk(fake_probe):
    ex = Executor.__new__(Executor)
    ex.recorder = _Rec()

def _scripted(mapping, calls):
    """构造一个按 (type, tag) 返回 True/False/抛异常的假 _dispatch_probe。

    mapping: {(type, tag): True|False|"raise"}
    calls:   调用记录列表，元素为 (type, tag)
    """
    def fake(act, app_name, allow_vision):
        key = (act.get("type"), act.get("tag"))
        calls.append(key)
        res = mapping.get(key, True)
        if res == "raise":
            raise StepError(f"模拟失败 {key}")
        return bool(res)
    return fake
